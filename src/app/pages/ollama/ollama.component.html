Local AI Settings (Ollama)
Local AI uses Ollama running on your machine. Make sure Ollama is installed and running before enabling. Ollama's API is OpenAI-compatible, so any model you have pulled (e.g. qwen2.5:7b) can be used here. Install Ollama and pull a model: ollama pull qwen2.5:7b
General Settings
Enable Local AI
If enabled, users can use chat commands to trigger the local AI.
Ollama Host
URL where Ollama is running. Default is http://localhost:11434
Model
The Ollama model to use for generation (e.g. qwen2.5:7b, llama3.2, mistral).
Chat Command
The command viewers type to trigger the local AI (e.g. !local, !ai).
Character Limit
The max amount of characters that will be converted into audio.
Message History
How many previous messages to send with each request for context.

Personality
Give your local AI a character. Leave blank for no personality.
Streamer's Identity
Who is the streamer? (e.g. "Alex, a horror game streamer")
AI's Identity
What is the AI's name/character? (e.g. "Shade, a sarcastic ghost")
AI's Core Identity
What type of being is it? (e.g. "ghost", "robot", "wizard")
AI's Background
Describe the AI's backstory and personality traits.
Streamer-AI Relationship
How does the AI relate to the streamer? (e.g. "reluctant companion")
Streamer's Thoughts on AI
How does the streamer perceive the AI? (e.g. "an annoying but helpful ghost")
